# fraud-detection-prevention-app

This repo is to iterate on a product to detect and prevent fraud through phishing and taking over of bank accounts.

Developer training has two flows:

1. [Navigate the repo and create something new](docs/training/01-navigate-and-create.md)
2. [How the classification core is wired to the phone](docs/training/02-how-the-core-is-wired.md)

Open both as step animations from [docs/training/animations/index.html](docs/training/animations/index.html). The written guide starts at [docs/training/README.md](docs/training/README.md).

The version 1 rules those guides follow are the iOS SMS filter specification on draft [PR #1](https://github.com/Higino/fraud-detection-prevention-app/pull/1).
